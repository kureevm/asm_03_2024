Программа написана на языке ассемблера TASM и предназначена для вычисления арифметического выражения с использованием знаковых переменных A, B и C. 
В ходе работы программа формирует числитель и знаменатель выражения, проверяет знаменатель на равенство нулю, выполняет знаковое целочисленное 
деление и сохраняет полученный результат в 32-битной переменной D. После завершения вычислений программа передает управление операционной системе.
(7*A^3+3*B^2+C−2​)/(6*B+C−A+8)
